# Berkontribusi

Terima kasih sudah mau membantu. Yang paling dibutuhkan:

- Perbaikan salah ketik atau penjelasan yang kurang jelas di `docs/`
- Contoh kode baru (bahasa atau tools lain) di `examples/`
- Laporan contoh yang tidak jalan

## Cara

1. Fork repo ini lalu buat branch baru.
2. Pastikan contoh kode tetap memakai variabel lingkungan `HUB_AI_KEY`, **jangan pernah menulis API key asli** di file mana pun.
3. Jalankan pemeriksaan sintaks yang sama dengan CI (lihat `.github/workflows/ci.yml`).
4. Buka pull request dan jelaskan apa yang berubah.

Layanan HUB AI sendiri tidak ada di repo ini, jadi laporan soal akun, saldo, atau top up sebaiknya lewat halaman kontak di website.
