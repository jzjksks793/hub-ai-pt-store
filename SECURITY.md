# Kebijakan Keamanan

## Melaporkan celah keamanan

Kalau kamu menemukan celah keamanan di layanan HUB AI atau di isi repo ini, **jangan** membukanya sebagai issue publik.

Hubungi kami lewat halaman kontak: https://hub-ai.ptstore.my.id/kontak. Tulis "Laporan keamanan" di pesanmu, jelaskan langkah untuk mereproduksi masalahnya, dan jangan sertakan data pengguna lain.

Kami akan membalas secepat mungkin dan memberi kabar setelah masalahnya diperbaiki.

## Kalau API key-mu bocor

Segera hubungi admin lewat halaman kontak supaya key diganti, dan jangan menyimpan key di repository publik atau kode front-end.

## Aturan pengujian

- Jangan mengakses, mengubah, atau menghapus data pengguna lain.
- Jangan melakukan serangan yang mengganggu layanan (DoS).
- Uji hanya dengan akunmu sendiri.
